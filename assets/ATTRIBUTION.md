# Jenkins artwork attribution

`jenkins-headshot.png` and `jenkins-logo.png` are unmodified official Jenkins artwork. The original Jenkins logo was created by Frontside. These files were downloaded from the [Jenkins artwork distribution](https://get.jenkins.io/art/jenkins-logo/256x256/) and are used under the [Creative Commons Attribution-ShareAlike 3.0 Unported License](https://creativecommons.org/licenses/by-sa/3.0/).

`jenkins-build-light.svg` and `jenkins-build-dark.svg` are adapted from the [Jenkins core `hammer.svg` symbol](https://github.com/jenkinsci/jenkins/blob/master/war/src/main/resources/images/symbols/hammer.svg). Its vector paths are unchanged; the dimensions and foreground colors are set for small light and dark entrypoints. The Jenkins core license is included in [JENKINS-CORE-LICENSE.txt](JENKINS-CORE-LICENSE.txt).

Artwork credit: [the Jenkins project](https://www.jenkins.io/). See its [artwork page](https://www.jenkins.io/artwork/) and [branding guidance](https://www.jenkins.io/press/). This plugin is a community-maintained integration and is not endorsed by the Jenkins project.
